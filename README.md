Cric is a responsive and visually appealing cricket-themed website built using React, React Router, and Tailwind CSS. It features a dynamic navigation bar, player profiles, upcoming matches, a media gallery, and a contact page. The website is designed with mobile responsiveness in mind and includes interactive UI elements such as dropdown navigation for small screens and stylish player cards. Ideal for showcasing front-end skills, component-based architecture, and Tailwind utility-first design.
